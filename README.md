# Følg norske satellitter rundt jorda

En interaktiv visualisering av norske satellitter.

## Publiser med GitHub Pages

1. Opprett et nytt, tomt GitHub-repository.
2. Fra repositoryet velger du **Add file → Upload files**.
3. Åpne denne mappen på datamaskinen, marker innholdet og dra filene og mappene inn i nettleseren.
4. Commit opplastingen til `main`.
5. Gå til **Settings → Pages**. Under **Build and deployment** velger du **Deploy from a branch**, deretter **main** og **/(root)**. Trykk **Save**.
6. Vent på at GitHub Pages publiserer siden. Nettadressen vises under **Settings → Pages**.
